# Getting help

NerdMiner_Craft is maintained as a hobby project. Please pick the channel that matches your need:

| What | Where |
|------|-------|
| Question / unsure if it's a bug | [GitHub Discussions](https://github.com/alexis2m/NerdMiner_Craft/discussions) |
| Bug report | [Open an issue](https://github.com/alexis2m/NerdMiner_Craft/issues/new?template=bug_report.yml) |
| Feature request | [Open an issue](https://github.com/alexis2m/NerdMiner_Craft/issues/new?template=feature_request.yml) |
| Theme / sprite proposal | [Open an issue](https://github.com/alexis2m/NerdMiner_Craft/issues/new?template=theme_proposal.yml) |
| Security report | [`SECURITY.md`](SECURITY.md) — email, do not open a public issue |

## Issues that are out of scope

NerdMiner_Craft is a fork. The following belong elsewhere:

- General NerdMiner_v2 questions or bugs that reproduce on the upstream firmware → [BitMaker-hub/NerdMiner_v2](https://github.com/BitMaker-hub/NerdMiner_v2).
- Hardware questions about the FNK0103 itself (defective unit, soldering, RMA) → [Freenove support](mailto:support@freenove.com).
- Mining pool issues (no shares accepted, payouts) → contact your pool. Default is [public-pool.io](https://web.public-pool.io).
- Bitcoin wallet / address questions → consult Bitcoin documentation; this project does not custody funds.

## Before opening an issue

1. **Search existing issues and discussions.** Most "the screen is white at boot" questions have already been answered.
2. **Update to the latest release.** Many bugs are fixed there.
3. **Capture a serial log at 115200 baud.** A picture of the screen plus 30 seconds of serial output covers ~80% of what we'll need.
